# Воркфлоу: анимация по раскадровке

Пример из практики: клип `assets/clips/oracle-v3/`, спрайты и раскадровка v2 в `assets/oracle/`.

1. **Бриф.** Скопируй `ai/templates/animation-brief.tmpl.md`, заполни. Пример готового: `ai/prompts/example-animation-brief.md` (исправь цвет волос по `canon/`!).
2. **Раскадровка** — схема: позы, камера, окружение, тайминги. Дизайн персонажа берётся не из неё, а из `splash-mascot.webp`.
3. **Сначала пересказ.** Модель пересказывает кадры и тайминги своими словами; ты правишь до начала работы.
4. **Ассеты слоями.** Герой (позы), стол, шар, пол, фон, листы — отдельные PNG на общем холсте. Это позволяет собирать сцену кодом без повторных генераций (как в `pipeline/oracle-v3/`).
5. **Сборка скриптом**, цикл бесшовный, палитра общая (в v3 — 64 цвета без дизеринга; для канона цель — не больше 20 на героиню).
6. **Экспорт** как клип (`assets/clips/<id>/`): `.aseprite` со слоями, спрайт-лист + JSON, WebP lossless (плагин), GIF (превью), `clip.json`. Покадровые PNG не коммитим.
7. **Приёмка**: `ai/qa-checklist.md`, кадр 1 и последний сравнить.

Правило экономии: если сцену можно собрать из уже готовых PNG, новых генераций не делаем.
