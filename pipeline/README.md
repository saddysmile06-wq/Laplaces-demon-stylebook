# pipeline: скрипты

Перенесены из рабочих папок. Лишних абсолютных путей в них нет: входные данные задаются аргументом или переменной окружения. Но часть скриптов читает данные, которых в репозитории нет (тяжёлые покадровые наборы), поэтому запускаются только у автора.

| Папка | Что делает | Запуск из репозитория |
|---|---|---|
| `mascot-gen/` | промпты, `postprocess.py`, анимации лежачей сцены (хвост, моргание, дыхание, подъём, свечи) | нет: нужны покадровые наборы `mascot-gen/out/anim/` и `ref/` из плагина |
| `pixellab/` | финализация поз, чистка, сборка сцены-цикла | нет: нужны `pixellab-out/` и кадры сцены v2 |
| `aseprite-redraw/` | `bust_build.py` (нужна переменная `PIXEL_ART_STUDIO`), `asm.lua` | частично |
| `oracle-v3/` | сборка «Лаплас проверяет судьбу»; `export-aseprite.lua` принимает `--script-param root=<папка final>` | нужны спрайты из `assets/oracle/sprites` и слои |
| `ui/` | полоса «думает» для плагина: `python make-thinking-strip.py "<путь к gif>"` | да, нужен только входной GIF |

Одноразовые черновики (`pipe.py`, `pipe2.py`, они были привязаны к временной папке сессии) лежат в `archive/aseprite-redraw/scripts/`: не запускать.

Если правишь скрипт: путь к данным принимай аргументом или переменной окружения. `tools/validate.py` предупредит, если в `pipeline/` вернётся `C:\...`.
