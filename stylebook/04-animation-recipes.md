# Как делаем анимации

Принцип: **без ИИ, где можно.** Лучший результат дают Python-скрипты над одним фиксированным кадром; ИИ нужен для новых поз.

| Что | Как | Скрипт |
|---|---|---|
| Хвост-лента | волна по хвосту | `pipeline/mascot-gen/make-tail-ribbon.py` |
| Моргание, дыхание | сдвиг слоёв | `make-blink.py`, `make-breath.py` |
| Подъём на локте | деформация торса | `make-rise.py` |
| Мерцание свечей | отдельные слои | `make-scene-anim-v*.py` |
| Полоса «думает» | 16 кадров 378×240 в одну ленту | `pipeline/ui/make-thinking-strip.py` |
| Новые позы | PixelLab, style-референс = предыдущий кадр | `ai/workflows/pixellab-notes.md` |
| Сцена-цикл | программная сборка из PNG | `pipeline/pixellab/build_scene.py`, `pipeline/oracle-v3/build.py` |

> Какие скрипты из `pipeline/` запускаются из репозитория, а каким нужны данные автора, смотри в `pipeline/README.md`.

## Правила цикла
- Последний кадр совпадает с первым (бесшовный цикл).
- Тайминги кратны 10 мс; типично 50 мс на кадр.
- Один кадр-стоп для «готово» (в Oracle кадр 93).
- Камера неподвижна, если бриф не говорит иное.
- Проверка кадра: `ai/qa-checklist.md`.

## Хранение кадров
Много кадров не значит много файлов. Клип = `.aseprite` + спрайт-лист + превью (`assets/clips/<id>/`). Покадровые PNG получаем командой `python tools/export.py`, в git их нет. Пример: `assets/clips/oracle-v3` (110 кадров, лист 0,6 МБ).

## Версии
Старые версии (`v1`, `v2`) лежат в `assets/animation/` и `archive/`; в плагин идёт только то, что помечено полем `plugin` в `assets/*/index.json`.
